## Lệnh thường dùng

```bash
npm run dev          # http://localhost:3000 (cần backend chạy ở :8080)
npm run lint         # ESLint
npm run build        # build production
npm run test:unit    # test hàm thuần trong lib/ (node --test)
npm run format       # Prettier
```

Biến môi trường: chép `.env.example` thành `.env.local` (`NEXT_PUBLIC_API_BASE_URL`, `NEXT_PUBLIC_WS_URL`).
